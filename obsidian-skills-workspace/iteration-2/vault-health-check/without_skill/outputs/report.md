## Key Findings and Recommendations

### 1. Short-ID Linking Problem (biggest issue)
The majority of broken links (~48) come from TaskNotes using **short IDs** like `[[ArkClaw-003]]` or `[[Infra-003]]` while the actual filenames are fully-slugged like `ArkClaw-003-add-opencode-provider-support.md`. Obsidian requires wikilinks to match the full filename (without extension). Fixing the link format in epic/story files would resolve roughly half of all broken links and many orphan notes simultaneously.

### 2. OHLCV-Service Path Issue
Six notes link to `[[OHLCV-Service]]` but the actual file lives in a subdirectory (`Infrastructure/Services/OHLCV-Service/`). Obsidian can resolve this if there is a file named `OHLCV-Service.md` -- verify whether it exists at the expected path or if an index file is needed.

### 3. Planned-but-Uncreated Notes
Twelve `ArkSignal-014` through `ArkSignal-025` links in the Freqtrade integration epic point to stories that have not been created yet. These are intentional placeholders but contribute to the broken link count.

### 4. Archived Notes are Islands
Archived tasks in `TaskNotes/Archive/` are both orphans and dead-ends. This is likely acceptable since they are completed work, but adding a backlink from an archive index would improve navigability.

### 5. Templates are Expected Orphans
The 4 template files in `_Templates/` and `TaskNotes/Templates/` are naturally orphaned -- they are used via Obsidian's template insertion, not via wikilinks.
